# 한글 → 히라가나 변환 규칙

구현: `app/src/main/java/me/algosketch/hanilkeyboard/hangul/HangulKanaMapper.kt`
테스트: `app/src/test/java/me/algosketch/hanilkeyboard/hangul/HangulTest.kt`

> 규칙을 바꾸면 이 문서와 테스트를 함께 수정한다.

## 0. 기본 원칙

1. **음절 단위 매핑**: 두벌식 오토마타로 조합된 음절(초성+중성+받침)을 단위로 변환한다.
2. **지연 매핑(문맥 의존)**: 각 음절의 변환 결과는 *자기 자신 + 바로 다음 음절의 초성*에 의해 결정된다.
   입력이 바뀔 때마다 버퍼 전체를 다시 매핑하므로, 뒤 음절이 입력되면 앞 음절의 결과가 바뀔 수 있다.
   - `각` → がく, `각ㅋ` → がっく, `각코` → がっこ, `각코우` → がっこう
   - 즉시 매핑했다면 `がㄱこう` 처럼 깨진다. 이를 막기 위한 설계이다.
3. 다음 음절에만 의존하므로, 앞쪽 음절을 잘라내도(부분 확정) 남은 음절의 결과는 변하지 않는다.
4. 일본어에 없는 발음은 **가장 비슷한 가나**로 변환한다.
5. 변환 결과(히라가나)는 내부 상태이며 화면(에디터)에는 한글이 표시된다. 히라가나는 후보 바의 0번 후보로만 보인다.

## 3. 받침 (다음 음절의 초성에 따라 결정)

| 받침 | 다음 초성 | 변환 | 예 |
|---|---|---|---|
| ㄱ ㄲ ㅋ | ㄱ ㄲ ㅋ | っ | 각코우 → がっこう |
| ㄱ ㄲ ㅋ | 그 외/끝 | く | 팍 → ぱく |
| ㅅ ㅆ ㅈ ㅊ ㄷ ㅌ ㅎ | 무관 | っ | 잣시/잦시/잧시 → ざっし, 맛테 → まって, 앗 → あっ |
| ㅂ ㅍ | ㅂ ㅃ ㅍ | っ | 캅푸 → かっぷ |
| ㅂ ㅍ | 그 외/끝 | ぷ | |
| ㄴ ㅇ | 무관 | ん | 혼 → ほん, 산포 → さんぽ |
| ㅁ | 자음(ㅇ 제외) | ん | 감바 → がんば |
| ㅁ | ㅇ/끝 | む | 킴 → きむ |
| ㄹ | 무관 | る | 할 → はる |
| 겹받침 (ㄳ ㄺ …) | | 앞 자음은 뒤 자음을 다음 초성으로 보고 변환 + 뒤 자음은 단독 자음 규칙 | 닭 → だるぐ |

## 4. 단독 자모

- 자음만 있는 단위: `ㅡ` 모음 규칙과 같다 (ㅋ → く, ㅅ → す, ㅆ → つ). 단 ㄴ, ㅇ → ん.
- 모음만 있는 단위: 초성 ㅇ 과 같다 (ㅏ → あ).

## 5. 기타 문자

- 장음 `ー`: 자판의 ー 키. 독음 버퍼에 그대로 들어간다 (코ー히ー → こーひー → コーヒー).
- 작은 가나 단독 입력(ぁ, ゃ 등)은 MVP 범위에서 제외 (요음·ㅘ 계열 조합으로만 생성).

## 6. 사전 조회 시 정규화

- 한글로는 ぢ/じ, づ/ず 구분이 어렵기 때문에 사전 조회 키에서 `ぢ→じ`, `づ→ず` 로 통합한다.
  (츠즈쿠 → つずく 로 입력해도 続く 후보가 나온다. 히라가나 후보는 입력한 그대로 표시.)
- 조사는 표기대로 입력한다: は = 하, を = 워, へ = 헤. (발음대로 `와` 를 입력하면 わ 가 된다.)
